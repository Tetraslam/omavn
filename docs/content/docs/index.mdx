---

omavn takes whatever you downloaded (a zip, a stack of split rars, an installer, a plain folder) and turns it into a game you can launch. It figures out the engine, runs installers unattended, and picks the best way to run it: natively where possible, through Proton otherwise.

## Install omavn

```bash
curl -fsSL https://omavn.dev/install.sh | sh
```

On Omarchy, also run `omavn omarchy setup`. See [Installing omavn](/docs/installing) for details.

## Add a game

Point it at the download exactly as you got it. Don't unzip anything first.

```bash
omavn install ~/Downloads/Himanatsu_final.zip
omavn install ~/Downloads/"Dies irae"          # a folder of MG1041_1.zip, _2.zip, _3.zip
omavn install ~/Downloads/"Yumina the Ethereal" # Setup.zip plus yumina1-3.dat
```

## Play it

```bash
omavn run dies-irae
```

Ids, prefixes, and title fragments all work: `omavn run dies`, `omavn run hima`. Or browse everything with `omavn library`; each game also shows up in your app launcher.

## Something broke?

```bash
omavn feedback --kind game --game dies-irae "voices cut out in chapter 2"
```

That opens a GitHub issue with your system details already filled in. See [Feedback](/docs/feedback).
