## Known quirks

- **Japanese games** get a Japanese locale automatically (detected from kana in file names or the exe's resource language). Without it, some engines fail to open files with Japanese names.
- **gamescope and some games:** a few games occasionally crash gamescope at startup. When that happens omavn retries in a plain window and keeps that setting for the game.

Your game not here? Try it, then tell us how it went:

```bash
omavn feedback --kind game --game <id> "works perfectly"
```

Reports of games that *work* are just as useful as broken ones.
