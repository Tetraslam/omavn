---
title: Installing omavn
description: One command to install, then omavn fetches what it needs.
---

```bash
curl -fsSL https://omavn.dev/install.sh | sh
```

If omavn.dev is blocked on your network (some campus firewalls block new domains), use the mirror: `curl -fsSL https://omavn.vercel.app/install.sh | sh`.

Installs the latest release to `~/.local/bin/omavn` (x86_64 and aarch64 Linux). Update any time with:

```bash
omavn self update
```

On Omarchy, follow up with `omavn omarchy setup` ([details](/docs/omarchy)).

## From source

Needs a Rust toolchain ([rustup.rs](https://rustup.rs)) and a C++ compiler (for the bundled unrar).

```bash
cargo install --git https://github.com/Tetraslam/omavn omavn
```

## What omavn downloads for you

Nothing is installed system-wide. Everything lives in `~/.local/share/omavn`, and omavn reuses what you already have before downloading anything.

| Runtime | When | Reused from |
| --- | --- | --- |
| GE-Proton | first Windows game | Steam's `compatibilitytools.d`, Steam's own Proton |
| umu-launcher | first Windows game | `umu-run` on your `PATH` |
| gamescope | never downloaded; install it with your package manager | `gamescope` on your `PATH` |
| Ren'Py (Linux) | first Ren'Py game of that version | |

You need `python3` (umu-launcher is a Python app), a working GPU driver including its 32-bit Vulkan libraries (most VNs are 32-bit), and ideally gamescope. `omavn doctor` checks them.

```bash
omavn doctor
```

## Where things go

| Path | What |
| --- | --- |
| `~/.local/share/omavn/games/<id>/files` | the game |
| `~/.local/share/omavn/games/<id>/prefix` | its Wine prefix, including saves |
| `~/.local/share/omavn/runtimes` | Proton, umu, Ren'Py |
| `~/.local/share/omavn/library` | one card image per game, for launchers |
| `~/.local/share/applications/omavn-<id>.desktop` | app launcher entries |
| `~/.config/omavn/catalog` | your own [catalog entries](/docs/catalog) |

Set `OMAVN_HOME` to keep everything under one directory instead.
